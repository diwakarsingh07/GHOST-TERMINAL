## 🕯️ What is HauntShell?

Around Halloween and Día de los Muertos, the veil between the living and the past grows thin. In computing, that veil is littered with the ghosts of deprecated runtimes, obsolete languages, abandoned web rings, and dead frameworks.

**HauntShell** is a retro CRT terminal and digital ofrenda powered by open-source AI:
1. **The Possessed Terminal**: Intercepts any command you type (`git commit`, `rm -rf`, `sudo reboot`, `npm install`) and whispers eerie, poetic, chilling commentary back into your console while tracking system "ectoplasm levels".
2. **The Digital Séance Altar (Ofrenda)**: Allows you to commune with the departed spirits of digital history:
   - ⚡ **The Ghost of Adobe Flash Player (1996 - 2020)**
   - 📜 **The Spirit of Ada Lovelace (1815 - 1852)**
   - 💳 **The Spectre of COBOL & Punch Cards (1959 - Present)**
   - 🕸️ **The Phantom of GeoCities & 56k Dial-Up (1994 - 2009)**
   - 👻 **The Ghost in the Machine (Kernel Wraith)**
3. **Eerie Web Audio Soundscape**: Includes a 100% offline, synthesized ambient drone generator built with the Web Audio API—no audio assets or streaming required.

## ⚡ Quick Start

### 1. Install & Run Web Terminal
```bash
cd D:\hackthon\ghost_in_the_machine
python app.py
```
Open **[http://127.0.0.1:8001](http://127.0.0.1:8001)** in your browser!

- Click **"Eerie Soundscape: OFF"** to turn on the synthesized haunted ambient audio.
- Type commands in the prompt (e.g. `rm -rf`, `git commit`, `npm install`) to hear the ghost whisper.
- Click **"🕯️ Digital Séance Altar"** to converse with Flash, Ada Lovelace, COBOL, and GeoCities.

### 2. Run Directly in Terminal (CLI Mode)
```bash
python cli.py
```

## 🌐 Why Open Innovation Matters

- **Preserving Digital Memory**: Día de los Muertos is about keeping memory alive without reliance on commercial cloud platforms that shut down, deprecate, or paywall history. Open-source local models guarantee that historical personas and computational memories remain accessible forever.
- **Offline in the Dark**: Works with the lights (and the internet) off.
- **Zero Cost & Infinite Communion**: Runs 100% locally with open weights (Ollama) or local fallbacks.
